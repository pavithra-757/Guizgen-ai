7-Agent System Architecture

1. Quiz Generator Agent

Generates high-quality question stems and options using Gemini AI prompt templates.

2. Answer Key Agent

Determines canonical correct answers, detailed explanations, and point values.

3. Quality Checker Agent

Audits clarity, checks distractor quality, difficulty match, and flags ambiguous questions.

4. Human Approval Agent

Enforces human-in-the-loop review. Blocks unapproved quizzes from being published.

5. Evaluation Agent

Auto-evaluates student responses against key rubrics (exact match & semantic scoring).

6. Weak Area Analyzer Agent

Detects student concept gaps (<70% accuracy) and formulates personalized study plans.

7. Central Agent Orchestrator

Sequences multi-agent pipelines and handles graceful fallback to Smart Demo Mode if needed.
